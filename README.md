## About
 
I design and deliver data platforms on the Microsoft stack for clients in the Netherlands. That means
setting the target architecture and then leading the team that builds it. It also means presales, so I am
usually in the room before the project exists.
 
Most engagements start from the same place. Reporting is scattered, the source system was never built to
be reported on, and nobody has two years to fix it. The parts I spend most of my time on are data
integration, platform security, and coaching the people who have to run the thing after I leave.
